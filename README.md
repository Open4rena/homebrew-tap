# Open4rena Homebrew Tap

Homebrew formulae for [o4](https://github.com/Open4rena/o4-releases), a
multi-provider agentic coding assistant for the terminal.

## Install

```bash
brew install open4rena/tap/o4
```

## Upgrade

```bash
brew update && brew upgrade o4
```

## Uninstall

```bash
brew uninstall o4
```

Formulae here point at the release archives published to
[Open4rena/o4-releases](https://github.com/Open4rena/o4-releases). The
`o4` formula is refreshed by `scripts/update-homebrew-formula.sh` in the
o4 source repository after each release.
